# Publication and privacy boundaries

This public case-study preview contains **limited, selectively quoted passages** from a historical unpublished creative planning document and text transcriptions of generated narrations. The rest of the manuscript and the full private archive are withheld. The project owner authorized proceeding with a public GitHub portfolio on October 24, 2026; approval to publish these excerpts does not authorize publication of the underlying full source material.

Do not add the complete creative master, private conversations, personal/medical/family details, identifiable third-party private data, company assessments, authentication material, private file paths or signed URLs. Deleting a secret from the latest GitHub version may not remove it from Git history.

Preserve quoted spelling and obvious transcription errors, including cases where a transcription may not faithfully reproduce the original audio. Avoid making a source-to-model causal claim when only artifacts or participant reports survive. If a later privacy concern arises, stop sharing that excerpt and make a documented correction; note that public Git history may still preserve earlier content.
